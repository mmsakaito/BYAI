## ✨ 项目简介

**BYAI 小智** 是一个基于 **ESP32-S3** 的软硬件探索项目。

从小智 AI 的基础功能出发，逐步实现音频驱动、触屏交互、聊天记录存储和电源管理，再探索自建服务端、模型自由选择，以及经典系统与游戏模拟器的运行。

**先把基础做扎实，再把想象力装进去。**

> [!NOTE]
> 以下为项目硬件配置与开发路线。未勾选的任务代表计划目标，不表示已经实现；进阶探索的可行性以实际验证为准。

## 🛠️ 硬件配置

| 模块 | 型号 / 规格 | 用途 |
| :--- | :--- | :--- |
| 🧠 主控 | **ESP32-S3** | 核心控制与应用运行 |
| 🎵 音频芯片 | **WM8978** | I2S 音频输入 / 输出 |
| 🔊 功放芯片 | **NS4110B** | 音频功率放大，标称最高 15 W |
| ⚡ 降压芯片 | **EA2208** | 3.3 V 降压供电 |
| 🔋 升压芯片 | **EA8101** | 升压供电 |
| 🔌 电池充电芯片 | **BQ25895** | 5 A 电池充电管理 |
| 🖥️ 触摸屏 | **2.4 英寸电容触摸屏** | 界面显示与触控交互 |

## 🗺️ 开发路线

### 第一阶段 · 基础功能

#### 🎵 音频驱动
- [ ] 完成 WM8978 全部寄存器的配置与控制。
- [ ] 实现 WM8978 音频输出。

#### 🖥️ 屏幕与交互
- [ ] 完成触摸屏适配，实现正常显示与触控。
- [ ] 实现通过触摸屏配置并连接 Wi-Fi。
- [ ] 构建基于 LVGL 的交互界面。
- [ ] 设计并加入更多表情。

#### 🤖 AI 与数据存储
- [ ] 基于小智官方固件进行修改。
- [ ] 支持连接小智官网模型服务。
- [ ] 基于 FlashDB 或 SQLite3 实现聊天记录保存。

#### 🔋 电源管理
- [ ] 实现 BQ25895 的 I2C 控制。
- [ ] 实现电池电量估算。
- [ ] 获取电流数据。

### 第二阶段 · 自建服务端

支持在设备端选择连接自建的 **小智 C# 服务端项目**，探索更灵活的模型与资源管理。

- [ ] 对接自建的小智 C# 服务端。
- [ ] 支持选择连接官方服务或自建服务端。
- [ ] 支持自主选择模型。
- [ ] 支持查看在线数量。
- [ ] 支持从服务端下载音乐。
