# BQ25890RTWT 基础通信与 USB 供电验证

> **2026-11-02 实物型号更正：** 用户抄录 U2 丝印为 `BQ25890HT1 898 A7SV`，
> 与 TI BQ25890H 的型号标识和 REG14=`0x1f`（PN=011、TS_PROFILE=1、DEV_REV=11）一致。
> 此板后续按 **BQ25890H** 手册核对；此前正文中的 BQ25890RTWT 是原图纸/需求基线，
> 不等同已确认的实物订货型号。仅凭顶部丝印不能确认卷带包装后缀 RTWR/RTWT。
> H 型号同样规定单次 ADC 完成后清启动位，因此型号更正尚不能解释启动位持续为 1。

对应 [Issue #24](https://github.com/mmsakaito/BYAI/issues/24)，属于 #5 电源管理首版基础通信。

以下历史验证仅开启基础通信测试（未开启 ADC），软件只发送寄存器地址并读取数据，不写充电控制、OTG、ADC、看门狗配置或持久化数据。
读取 REG0C 会消费锁存故障；每轮分别记录第一次历史值和第二次当前值，NTC 始终为当前状态。
输出字段、编码以 [TI BQ25890 数据手册](https://www.ti.com/lit/ds/symlink/bq25890.pdf)
的 REG0B、REG0C、REG14 为依据。型号匹配只验证 PN，不验证封装、订货后缀或整板焊接。

## 实板步骤与通过条件

1. 取得烧录授权，确认板版本、固件提交、串口、配置、电池已断开，并记录 USB 接口和电源规格。
   由操作者检查 I²C 上拉和电平。不得短接总线或带电拆线制造通信错误。
2. 使用万用表记录 VBUS、SYS、3V3；记录探针位置，并按电路及器件允许范围判断。
   SYS 为电源路径输出，不预先假定固定为 5 V。只记录实测，不把标称值填为测量值。
3. 烧录测试版本并保存完整启动日志；确认 PN=3、基础状态每秒可读。
   `valid=1` 表示通信成功，故障字段须另外判读；不推断电池连接或宣称充电完成。
4. USB 断电重启 5 次，记录每次启动及芯片识别。连续运行 10 分钟，记录成功/失败计数、
   当前及历史故障、重启与可观察异常；彩条同时开启时确认画面仍轮换。
5. 异常即停止相应硬件操作并排查，不擦除 Flash/NVS。结束后关闭串口并保存日志。

通过要求：5 次上电均识别、10 分钟读取无通信失败或非预期重启，测量符合电路及器件范围；
对出现的芯片故障位有记录和解释。任一项未完成则保留未验收状态。
跨模块 30 分钟整机结果由 #42 汇总；电池运行、供电切换、充电控制、电量/电流及界面不在本轮。

### 实板装配补充：R17 未焊

- 用户确认本块板 R17 未焊。已有网表中 R17 与 R20 均接 TS–GND，R16 接 REGN–TS；
  因此 R17 未焊时，TS 仍由 R16/R20 形成分压，不能将 TS 节点记录为完全悬空。
- 已有网表将 R16、R17、R20 均标为 10k。若实物 R16/R20 均为 10k 且连接符合该网表，
  R17 未焊时理想 TS/REGN 为 50%，以实测 REGN=5.04V 计算 TS≈2.52V。
  当前实测 TS=3.42V（67.86%），与该理想分压不同；实装 R16/R20 阻值和连接仍待核对。
- 这是图纸标称与实板条件之间的待核对项，不归因为固件通信错误；本轮不更改电阻或屏蔽 NTC 状态。

  R20 暂按可能的 `01C` 解读，EIA-96 中为 10kΩ，仍待清晰丝印或断电阻值确认。
