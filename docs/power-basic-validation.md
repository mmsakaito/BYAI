## 配置与接线基线

| 项目 | 本轮基线 | 证据或限制 |
| --- | --- | --- |
| 板卡 | 20261001 | 实际接板时再次核对 |
| 电源芯片 | BQ25890RTWT（U2） | 原理图/PRD；实物需通过 REG14 身份核对 |
| SCL / SDA | GPIO38 / GPIO39 | 原理图网表；与音频和触控共用 |
| INT | GPIO4 | 成员确认接线；本次不配置/不启用中断 |
| I²C | 7 位地址 0x6A，100 kHz，单事务超时 100 ms | 外部上拉及实际电平接板前检查 |
| 供电 | USB，不接电池 | 实际接口、线材、电源额定规格待记录 |
| 固件配置 | ESP32-S3；`CONFIG_BYAI_POWER_BASIC_TEST=y` | 默认关闭；可与彩条同时开启 |

软件只发送寄存器地址并读取数据，不写充电控制、OTG、ADC、看门狗配置或持久化数据。
读取 REG0C 会消费锁存故障；每轮分别记录第一次历史值和第二次当前值，NTC 始终为当前状态。
输出字段、编码以 [TI BQ25890 数据手册](https://www.ti.com/lit/ds/symlink/bq25890.pdf)
的 REG0B、REG0C、REG14 为依据。型号匹配只验证 PN，不验证封装、订货后缀或整板焊接。

## 软件验证

- 主机命令：仓库根目录运行 `bash firmware/tests/power/run.sh`。
- 模拟覆盖：状态与故障位编码、芯片身份、无应答、NACK、超时、每个读取位置失败、
  清空旧数据和设备资源释放；故障第二次读取失败也不输出有效数据。
- ESP-IDF 构建：在已激活的 ESP-IDF 终端进入 `firmware/`，配置开关后运行 `idf.py build`。
  分别检查测试关闭，以及电源测试和彩条同时开启两种配置，确认目标和 `.bin`/`.elf` 产物。
- 软件验证结果不代表芯片识别或实际供电验证通过；实际执行结果见下表。

## 实板步骤与通过条件

1. 取得烧录授权，确认板版本、固件提交、串口、配置、电池已断开，并记录 USB 接口和电源规格。
   由操作者检查 I²C 上拉和电平。不得短接总线或带电拆线制造通信错误。
2. 使用万用表记录 VBUS、SYS、3V3；记录探针位置，并按电路及器件允许范围判断。
   SYS 为电源路径输出，不预先假定固定为 5 V。只记录实测，不把标称值填为测量值。
3. 烧录测试版本并保存完整启动日志；确认 PN=3、基础状态每秒可读。
   `valid=1` 表示通信成功，故障字段须另外判读；不推断电池连接或宣称充电完成。
4. USB 断电重启 5 次，记录每次启动及芯片识别。连续运行 10 分钟，记录成功/失败计数、
   当前及历史故障、重启与可观察异常；彩条同时开启时确认画面仍轮换。
5. 异常即停止相应硬件操作并排查，不擦除 Flash/NVS。结束后关闭串口并保存日志。

通过要求：5 次上电均识别、10 分钟读取无通信失败或非预期重启，测量符合电路及器件范围；
对出现的芯片故障位有记录和解释。任一项未完成则保留未验收状态。
跨模块 30 分钟整机结果由 #42 汇总；电池运行、供电切换、充电控制、电量/电流及界面不在本轮。

  这些复位不等同于 USB 断电重启，不能计入 5 次上电验收。

### 实板装配补充：R17 未焊

- 用户确认本块板 R17 未焊。已有网表中 R17 与 R20 均接 TS–GND，R16 接 REGN–TS；
  因此 R17 未焊时，TS 仍由 R16/R20 形成分压，不能将 TS 节点记录为完全悬空。
- 已有网表将 R16、R17、R20 均标为 10k。若实物 R16/R20 均为 10k 且连接符合该网表，
  R17 未焊时理想 TS/REGN 为 50%，以实测 REGN=5.04V 计算 TS≈2.52V。
  当前实测 TS=3.42V（67.86%），与该理想分压不同；实装 R16/R20 阻值和连接仍待核对。
- 这是图纸标称与实板条件之间的待核对项，不归因为固件通信错误；本轮不更改电阻或屏蔽 NTC 状态。

### 实装丝印补充与分压复核

- 用户报告 R16 丝印 `472`（按三位码为 4.7kΩ），R20 丝印“好像是 0IC”。
  R20 暂按可能的 `01C` 解读，EIA-96 中为 10kΩ，仍待清晰丝印或断电阻值确认。
  编码依据：[Yageo 电阻标记规则](https://www.yageogroup.com/content/Resource%20Library/Product%20Guide-Catalog/yageo_PYu-R_Marking_3_19050818_924.pdf)。
- R17 未焊，若 R16=4.7kΩ、R20=10kΩ，则 TS/REGN=10/(4.7+10)≈68.03%，
  REGN=5.04V 时 TS≈3.429V，与实测 3.42V 接近。
- 因而此前“两颗均 10k 时应为 2.52V”的差异可由 R16 实装 4.7kΩ 解释，
  不再仅凭此差异怀疑焊接连接；保留 R20 编码尚未完全确认的限制。
- R16 实装值与已有网表标称 10k 不同，记录为装配差异；本轮不修改电阻或屏蔽 TS Cool，
  不将固定分压当作真实电池温度检测验证。
